# Cinematic theme assets

- cinema-login.jpg and cinema-header.jpg: clean scene crops from the UI references supplied by the project owner for this redesign. No UI controls are baked into the backgrounds.
- fonts/Manrope-*.ttf: static 400/600/700 instances of the Google Fonts Manrope variable font, generated with fontTools 4.60.1 for reliable native Qt weight selection. SIL Open Font License 1.1 is retained in fonts/OFL.txt. Upstream: https://github.com/google/fonts/tree/main/ofl/manrope.
- Existing drone.png remains the project bee identity.
