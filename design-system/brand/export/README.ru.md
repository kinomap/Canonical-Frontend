# KINOSOTA — комплект логотипов

Подготовлено по предоставленному референсу. 3D-персонаж — адаптация с помощью генерации изображений; надпись KINOSOTA набрана отдельно и переведена в контуры. Пчёлка жёлтая, левая для зрителя линза синяя, правая красная.

## Версии
- `kinosota-main` — основной вертикальный знак с названием, PNG 800×800.
- `kinosota-horizontal` — пчёлка + название для шапки и подвала, PNG 1024×240.
- `kinosota-compact` — 3D-пчёлка без надписи, PNG 512×512.
- `kinosota-icon` — самостоятельная упрощённая векторная иконка для малых размеров.
- `*-light.svg` — тёмная надпись KINO для светлой поверхности. В остальных версиях KINO светлая, SOTA золотая.
- PNG с прозрачным фоном. SVG без внешних шрифтов и сетевых запросов.
- ICO содержит кадры 16, 32, 48, 128 и 256 px. Отдельные PNG также включают 180, 192 и 512 px.

## Важное о SVG
Упрощённая иконка полностью векторная. 3D-версии — гибридные SVG: встроенная растровая пчёлка на прозрачном фоне плюс векторная надпись. Они не являются полностью векторной 3D-иллюстрацией; для очень крупной печати потребуется отдельный исходник большей детализации.

Не растягивать знак непропорционально и не обрезать усики. Сохранять свободное поле не менее 12% от размера знака. На 16–32 px использовать упрощённую иконку. Не добавлять квадратную плашку вокруг персонажа.

Палитра: мёд #ffce21, синий #00bfff, красный #ff3438, тёмный #171820, светлый #fff8eb.
